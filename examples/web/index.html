One row per electrode, then accelerometer and gyroscope with their three axes overlaid. Every row is mean-removed and scaled to its own peak over the window; the figure after the name is that peak. Smoothing draws a 9-sample moving average over a dimmed copy of the raw trace — the same window the TUI uses, so the two agree. Drawing happens in a worker on an OffscreenCanvas, so the main thread is left to the Bluetooth it cannot delegate. Needs a Web Bluetooth browser — Chrome or Edge — on localhost or HTTPS.
